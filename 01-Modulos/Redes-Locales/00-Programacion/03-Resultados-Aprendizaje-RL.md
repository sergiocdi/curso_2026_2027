# 3. Resultados de Aprendizaje y Ponderaciones

| RA | Enunciado Oficial | Ponderación |
| :---: | :--- | :---: |
| **[[RA01-Arquitectura-Redes\|RA1]]** | Reconoce la estructura de las redes locales identificando sus elementos constitutivos y las topologías estándar. | **15%** |
| **[[RA02-Medios-Transmision-Cableado\|RA2]]** | Despliega el cableado de una red local reconociendo los medios de transmisión y aplicando técnicas de montaje normalizadas. | **20%** |
| **[[RA03-Configuracion-Conmutadores-Routers\|RA3]]** | Interconecta equipos en redes locales utilizando conmutadores y enrutadores y configurando sus parámetros básicos. | **25%** |
| **[[RA04-Direccionamiento-IPv4-IPv6\|RA4]]** | Configura el direccionamiento IP de los equipos resolviendo problemas de conectividad en redes con subredes (IPv4 e IPv6). | **25%** |
| **[[RA05-Servicios-Red-DHCP-DNS\|RA5**]] | Configura servicios básicos de red local (DHCP, DNS) monitorizando el tráfico y verificando su correcto funcionamiento. | **15%** |
| **Total** | | **100%** |
