# 10. Recursos y Plataformas a Distancia

- **Campus Virtual Moodle Educastur**: Plataforma oficial de gestión del aprendizaje, entrega de tareas, foros técnicos y avisos.
- **Microsoft Teams / Google Meet**: Herramientas para la impartición de las 2 horas de clase virtual síncrona los lunes.
- **Entorno de Trabajo (IDE)**: El entorno de desarrollo principal para las demostraciones en las sesiones síncronas y guías es **Eclipse IDE**, si bien el alumnado en modalidad a distancia tiene plena libertad para emplear otros entornos (IntelliJ IDEA, VS Code) siempre que los proyectos cumplan los estándares de compilación Maven/Java 21.
- **Software y Ecosistema**: JDK 21 LTS, Apache Maven, Oracle Database (local o contenedor Docker), MongoDB Community y Git.
- **GitHub / GitHub Classroom**: Plataforma de control de versiones y entrega de proyectos individuales.
- **Aula C212 (CIFP Avilés)**: Puesto docente para emisión de clases virtuales y sede física para la realización de los exámenes presenciales oficiales.
