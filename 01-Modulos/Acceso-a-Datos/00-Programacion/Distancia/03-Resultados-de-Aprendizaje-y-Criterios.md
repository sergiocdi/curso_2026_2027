# 3. Resultados de Aprendizaje y Criterios de Evaluación

El currículo oficial del módulo se estructura en 6 Resultados de Aprendizaje (RAs):

1. **RA1 (15%)**: Desarrolla aplicaciones que gestionan información almacenada en ficheros, identificando el campo de aplicación de los mismos y utilizando clases específicas de flujos y la API Java NIO.2.
2. **RA2 (20%)**: Desarrolla aplicaciones que gestionan información en sistemas gestores de bases de datos relacionales, utilizando conectores (JDBC), pools de conexiones y sentencias SQL avanzadas con transacciones ACID.
3. **RA3 (25%)**: Gestiona la persistencia de los datos mediante herramientas de mapeo objeto-relacional (ORM), utilizando Spring Boot 3, Spring Data JPA e Hibernate sobre bases de datos empresariales.
4. **RA4 (10%)**: Desarrolla aplicaciones que gestionan información almacenada en bases de datos objeto-relacionales y nativas orientadas a objetos y XML.
5. **RA5 (20%)**: Desarrolla aplicaciones que almacenan y consultan información en sistemas gestores de bases de datos no relacionales (NoSQL) orientadas a documentos (MongoDB).
6. **RA6 (10%)**: Desarrolla y empaqueta componentes visuales y no visuales de acceso a datos, garantizando su reutilización e integración.
