Texto Plano

Problema Profesional: Migración de ficheros legados exportados por bases de datos antiguas en Windows (ISO-8859-1 o Windows-1252) hacia servidores web modernos en Linux (UTF-8), donde caracteres como tildes, eñes y diéresis se rompen visualmente (*Mojibake*).

📂 Datos de Prueba (Crea datos/usuarios_legacy.txt en ISO-8859-1):
1;García;Administración;garcia@empresa.com
2;Muñoz;Diseño Gráfico;munoz@empresa.com
3;Peña;Logística y Almacén;pena@empresa.com
🛠️ Instrucciones Java Clave:
Instrucción / MétodoParámetrosUtilidad
Files.newBufferedReader(...)Path, StandardCharsets.ISO_8859_1Abre flujo de lectura decodificando los bytes en ISO-8859-1.
Files.newBufferedWriter(...)Path, StandardCharsets.UTF_8Abre flujo de escritura codificando en UTF-8 estándar.
br.readLine()NingunoLee una línea completa hasta \n. Devuelve null al final.
bw.write(s); bw.newLine();StringEscribe la línea y añade el separador de salto de línea de la plataforma.
📝 Procedimiento Paso a Paso:
  1. Crea la clase Actividad1_1_Charset en el paquete act1_texto.
  2. Define las rutas: Path origen = Path.of("datos", "usuarios_legacy.txt"); y Path destino = Path.of("datos", "usuarios_utf8.txt");.
  3. Abre ambos flujos en un try-with-resources para garantizar el cierre seguro de archivos.
  4. Implementa un bucle while ((linea = br.readLine()) != null) escribiendo cada línea con bw.write(linea) y bw.newLine().

✅ Resultado Esperado: Al abrir datos/usuarios_utf8.txt en el editor, las palabras Administración, Diseño y Logística deben verse perfectas sin ningún símbolo extraño. Consola: ✅ Migración completada: 3 líneas convertidas a UTF-8.

MétodoClaseUtilidad

📌 Actividad 2.2: Detección Limpia de Fin de Archivo con EOFException
Momento de Aula: Tras Diapositiva 10 Paquete: act2_binarios Clase: Actividad2_2_DataInputStreamEOF.java
EOF Control

Problema Profesional: Leer secuencialmente un archivo binario hasta el final con DataInputStream. Al leer números primitivos, un -1 puede ser un dato real válido (temperatura negativa), por lo que Java no retorna -1 ni null, sino que lanza obligatoriamente EOFException.

🛠️ Instrucciones Java Clave:
try (DataInputStream dis = new DataInputStream(new BufferedInputStream(new FileInputStream(f)))) {
    while (true) {
        int id = dis.readInt();
        String nom = dis.readUTF();
        double temp = dis.readDouble();
        boolean alr = dis.readBoolean();
        System.out.printf("[%d] %s: %.2fºC (Alarma: %b)%n", id, nom, temp, alr);
    }
} catch (EOFException e) {
    System.out.println("✅ Fin de fichero alcanzado limpiamente.");
}
⚠️ Alerta de Examen: Debes leer los campos en el mismo orden exacto en que fueron escritos. Si intentas leer readDouble() donde se escribió un int, los bytes se desfasarán por completo corrompiendo la lectura.
📌 Actividad 2.3: Modificación Directa con RandomAccessFile (RAF)
Momento de Aula: Tras Diapositivas 11 y 12 Paquete: act2_binarios Clase: Actividad2_3_RandomAccessFile.java
RAF

Problema Profesional: Actualizar directamente en el disco físico el salario de un empleado concreto de una base de datos sin leer ni duplicar los demás registros.

📐 Matemáticas del Registro Fijo (36 Bytes):

id (4B) + apellido (10 chars con writeChars = 20B) + departamento (4B) + salario (8B) = 36 Bytes.

  • Inicio del registro i: offset_base = i * 36
  • Ubicación del salario en registro i: offset_salario = (i * 36) + 28 (4 + 20 + 4)
🛠️ Instrucciones Java Clave:
MétodoUtilidad
raf.seek(long pos)Posiciona el cabezal en el byte absoluto pos.
raf.writeDouble(nuevoSalario)Sobrescribe los 8 bytes del salario en disco.
raf.getFilePointer()Devuelve la posición actual del cursor.
raf.length()Devuelve el tamaño total en bytes del fichero.
📝 Procedimiento Paso a Paso:
  1. Crea el archivo datos/empleados.dat con 3 empleados.
  2. Implementa modificarSalario(int posicion, double nuevoSalario):
    • Calcula el offset exacto: (posicion * 36) + 28.
    • Abre con new RandomAccessFile(f, "rw").
    • Ejecuta raf.seek(offset) y raf.writeDouble(nuevoSalario).
  3. Vuelve a leer el registro situando el cursor en posicion * 36 y verifica que el salario se actualizó sin tocar el resto de datos.

📌 Actividad 2.5: El Gran Reto - Persistencia Incremental sin StreamCorruptedException
Momento de Aula: Tras Diapositivas 14 y 15 Paquete: act2_binarios Clase: Actividad2_5_AppendObjetos.java
MiObjectOutputStream

Problema Profesional: Añadir objetos a un fichero serializado existente con FileOutputStream(f, true) provoca el colapso del stream con StreamCorruptedException: invalid type code: AC, debido a que el constructor de ObjectOutputStream inyecta una cabecera de 4 bytes intermedia en mitad del archivo.

🛠️ Solución Docente Canónica:
// 1. Subclase que anula la escritura de cabecera intermedia
class MiObjectOutputStream extends ObjectOutputStream {
    public MiObjectOutputStream(OutputStream out) throws IOException { super(out); }
    @Override
    protected void writeStreamHeader() throws IOException {
        // Al dejar este método vacío, NO se escribe cabecera secundaria
    }
}

// 2. Patrón de apertura según estado del fichero
boolean yaExisteConDatos = f.exists() && f.length() > 0;
try (FileOutputStream fos = new FileOutputStream(f, true);
     ObjectOutputStream oos = yaExisteConDatos 
             ? new MiObjectOutputStream(fos) 
             : new ObjectOutputStream(fos)) {
    oos.writeObject(nuevoUsuario);
}
✅ Resultado Esperado: Al ejecutar el programa 3 veces y leer todos los objetos con un bucle while(true) hasta EOFException, se recuperan todos los registros limpiamente sin ninguna excepción de corrupción.

📌 Actividad 3.4: Mapeo Declarativo Objeto-XML con JAXB
Momento de Aula: Tras Diapositiva 20 Paquete: act3_xml Clases: Curso.java, Actividad3_4_JAXBMapeo.java
JAXB

Problema Profesional: Persistir y recuperar entidades complejas en XML mediante anotaciones declarativas (Jakarta XML Binding) sin manipular nodos DOM manualmente.

🛠️ Código Esencial:
@XmlRootElement(name = "curso")
@XmlAccessorType(XmlAccessType.FIELD)
public class Curso {
    @XmlAttribute private String codigo;
    @XmlElement private String nombre;
    @XmlElement private int horas;
    public Curso() {} // ¡Constructor vacío obligatorio para JAXB!
}

// Marshaller (Java -> XML)
JAXBContext ctx = JAXBContext.newInstance(Curso.class);
Marshaller m = ctx.createMarshaller();
m.setProperty(Marshaller.JAXB_FORMATTED_OUTPUT, true);
m.marshal(curso, new File("datos/curso.xml"));

// Unmarshaller (XML -> Java)
Curso c = (Curso) ctx.createUnmarshaller().unmarshal(new File("datos/curso.xml"));
