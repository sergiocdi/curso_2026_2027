📂 Bloque 1 · Conectividad y CRUD
Actividad 2.1: Conexión Inicial y Diagnóstico con Oracle Database 23c
Básica · 25 minutos
Alineación Curricular: RA2 (CE2.a, CE2.b)
Entorno: Java 21 · Oracle 23c · Maven

Configuración de las dependencias Maven para el driver oficial Oracle JDBC (ojdbc11), creación de una clase de utilidad de conexión con DriverManager, y verificación de los metadatos de versión y compatibilidad del motor.

🛠️ Instrucciones y Métodos Clave
Instrucción / MétodoAcción en Memoria / Servidor / Red
DriverManager.getConnection(url, user, pass)Abre un socket TCP contra el listener de Oracle en el puerto 1521, autentica al usuario c##dam2_user y establece la sesión JDBC.
Connection.getMetaData().getDatabaseProductVersion()Consulta el catálogo del motor y devuelve la cadena con la versión exacta de Oracle Database (ej. Oracle Database 23c Free Release).
Connection.close() (try-with-resources)Cierra la sesión y libera los recursos en el servidor de base de datos.
🎯 Enunciado del Reto de Aula

Crea un proyecto Maven llamado `ad-ut2-conectores` e incorpora la dependencia `com.oracle.database.jdbc:ojdbc11:23.3.0.23.09`. Desarrolla una clase `ConexionOracleTest` que solicite los parámetros de conexión y confirme el estado de la base de datos imprimiendo la versión del motor y el catálogo predeterminado.

Actividad 2.2: Operaciones CRUD con PreparedStatement y Claves Autogeneradas
Intermedia · 35 minutos
Alineación Curricular: RA2 (CE2.c, CE2.d)
Entorno: Java 21 · Oracle 23c · Maven

Creación de la tabla de productos con columna identity en Oracle, inserción de registros parametrizados recuperando el ID generado con Statement.RETURN_GENERATED_KEYS, actualización de stock y eliminación controlada.

🛠️ Instrucciones y Métodos Clave
Instrucción / MétodoAcción en Memoria / Servidor / Red
conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)Precompila la sentencia SQL de inserción habilitando el canal de retorno para los identificadores generados automáticamente.
ps.setBigDecimal(index, valor) / ps.setString(index, valor)Asigna parámetros fuertemente tipados a las posiciones '?' de la sentencia precompilada sin riesgo de inyección SQL.
ps.executeUpdate()Ejecuta la sentencia DML en Oracle y retorna el número de filas afectadas en la base de datos.
ps.getGeneratedKeys()Retorna un ResultSet especial que contiene las claves primarias autogeneradas por la base de datos.
🎯 Enunciado del Reto de Aula

Crea la tabla `productos` en tu esquema Oracle con columnas `id_producto NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`, `nombre VARCHAR2(100)`, `precio NUMBER(10,2)`, `stock NUMBER(5)`. Desarrolla una clase `GestionProductosCRUD` que inserte 2 productos recuperando sus IDs generados, actualice el precio del primero y verifique el conteo de filas afectadas.

Actividad 2.3: Navegación de ResultSet y Tratamiento Estricto de NULLs
Intermedia · 30 minutos
Alineación Curricular: RA2 (CE2.c, CE2.e)
Entorno: Java 21 · Oracle 23c · Maven

Consulta con filtros dinámicos, navegación mediante ResultSet, obtención tipada de fechas con la API moderna java.time (LocalDate) y resolución segura de columnas numéricas que admiten valores NULL en Oracle.

🛠️ Instrucciones y Métodos Clave
Instrucción / MétodoAcción en Memoria / Servidor / Red
ResultSet.next()Avanza el cursor interno a la siguiente fila de resultados. Retorna true si hay registro, false al finalizar.
ResultSet.wasNull()Comprueba si la última columna primitiva leída (getInt, getDouble, getLong) contenía un valor NULL en la base de datos.
ResultSet.getObject(col, Class)Método moderno de JDBC 4.2 que deserializa directamente tipos de datos complejos y permite retornar null para wrappers como Integer, Double o LocalDate.
🎯 Enunciado del Reto de Aula

Añade una columna `descuento NUMBER(5,2)` a la tabla `productos` que admita nulos. Inserta un producto sin descuento y otro con 10% de descuento. Desarrolla un programa que consulte todos los productos e imprima en consola si el descuento es NULL o tiene un valor numérico real, utilizando tanto `wasNull()` como `rs.getObject("descuento", Double.class)`.

Actividad 2.4: Invocación de Procedimientos Almacenados PL/SQL
Avanzada · 35 minutos
Alineación Curricular: RA2 (CE2.f)
Entorno: Java 21 · Oracle 23c · Maven

Creación de un procedimiento PL/SQL en Oracle con parámetros IN y OUT, e invocación desde Java mediante CallableStatement, registrando los tipos SQL de salida con java.sql.Types.

🛠️ Instrucciones y Métodos Clave
Instrucción / MétodoAcción en Memoria / Servidor / Red
conn.prepareCall("{ call sp_nombre(?, ?) }")Crea la sentencia invocadora de subprogramas en el servidor de base de datos.
cs.setLong(index, valor)Asigna valores a los parámetros formales de entrada (IN).
cs.registerOutParameter(index, Types.TIPO)Declara ante el driver JDBC qué tipo de dato SQL se espera recibir de un parámetro de salida (OUT).
cs.execute()Ejecuta el bloque PL/SQL en el motor Oracle.
cs.getBigDecimal(index) / cs.getString(index)Extrae el valor devuelto por el parámetro de salida tras la ejecución.
🎯 Enunciado del Reto de Aula

Crea en Oracle el procedimiento `sp_resumen_producto(p_id IN NUMBER, p_precio OUT NUMBER, p_estado OUT VARCHAR2)`. Si el stock es > 0 el estado es 'DISPONIBLE', si es 0 'AGOTADO'. Desarrolla una clase Java `InvocacionPLSQLTest` que ejecute el procedimiento para un producto dado y muestre sus parámetros OUT.

📂 Bloque 2 · Transacciones y Pools
Actividad 2.5: Gestión Transaccional ACID Bancaria y Savepoints
Avanzada · 40 minutos
Alineación Curricular: RA2 (CE2.d, CE2.g)
Entorno: Java 21 · Oracle 23c · Maven

Control manual de transacciones para garantizar atomicidad absoluta en transferencias de fondos entre cuentas bancarias. Uso de setAutoCommit(false), commit(), rollback() en bloque catch y creación de Savepoints intermedios.

🛠️ Instrucciones y Métodos Clave
Instrucción / MétodoAcción en Memoria / Servidor / Red
conn.setAutoCommit(false)Desactiva la confirmación inmediata automática. Comienza un bloque transaccional atómico.
conn.setSavepoint("nombre")Establece un punto de restauración intermedio dentro de la transacción activa.
conn.rollback(savepoint)Deshace exclusivamente las operaciones realizadas con posterioridad al savepoint indicado.
conn.commit()Confirma de manera permanente y atómica todas las operaciones de la transacción en el almacenamiento de Oracle.
conn.setAutoCommit(true)Restaura el estado original de la conexión en el bloque finally.
🎯 Enunciado del Reto de Aula

Crea una tabla `cuentas_bancarias (id NUMBER PRIMARY KEY, titular VARCHAR2(50), saldo NUMBER(10,2))`. Inserta dos cuentas con 1.000€ cada una. Realiza una transferencia transaccional de 300€ de la cuenta 1 a la cuenta 2. Simula un fallo de negocio (saldo insuficiente o excepción) y comprueba que ningún saldo queda modificado gracias al rollback.

Extracción dinámica de las tablas del esquema mediante DatabaseMetaData y visualización de columnas, tipos SQL y dimensiones de cualquier consulta genérica con ResultSetMetaData.

🛠️ Instrucciones y Métodos Clave
Instrucción / MétodoAcción en Memoria / Servidor / Red
conn.getMetaData().getTables(cat, schema, tablePattern, types)Consulta el catálogo del motor y retorna las tablas que coinciden con los filtros.
ResultSet.getMetaData()Retorna la interfaz ResultSetMetaData asociada a una consulta activa.
ResultSetMetaData.getColumnCount()Devuelve el número total de columnas proyectadas en el SELECT.
ResultSetMetaData.getColumnLabel(i) / getColumnTypeName(i)Devuelve el nombre de la columna (o alias) y su tipo nativo en Oracle.

Desarrolla un visor de tablas dinámico `VisorEsquemaOracle` que liste todas las tablas del usuario `c##dam2_user` y, para cada una de ellas, muestre el nombre de sus columnas, tipo de dato SQL y si admite valores nulos.

Actividad 2.7: Configuración de Pool HikariCP y Benchmark Concurrente
Avanzada · 35 minutos
Alineación Curricular: RA2 (CE2.h)
Entorno: Java 21 · Oracle 23c · Maven

Configuración de un pool HikariDataSource de alto rendimiento en Java 21 y comparativa de tiempos de respuesta frente al DriverManager clásico ejecutando 100 consultas consecutivas.

🛠️ Instrucciones y Métodos Clave
Instrucción / MétodoAcción en Memoria / Servidor / Red
new HikariConfig()Objeto de configuración de parámetros del pool: URL, credenciales, tamaños de piscina y timeouts.
config.setMaximumPoolSize(10)Fija el número máximo de conexiones físicas simultáneas mantenidas contra Oracle.
new HikariDataSource(config)Inicializa el pool y pre-calienta las conexiones mínimas en segundo plano.
dataSource.getConnection()Toma una conexión pre-calentada del pool en microsegundos.
conn.close() (con HikariCP)Interceptado por el proxy del pool: la conexión física no se destruye, sino que se devuelve a la piscina.
🎯 Enunciado del Reto de Aula

Añade `com.zaxxer:HikariCP:5.1.0` a tu `pom.xml`. Implementa una clase `BenchmarkPoolHikari` que ejecute 100 consultas `SELECT 1 FROM DUAL`. Primero usando `DriverManager.getConnection()` en cada iteración y luego usando `HikariDataSource.getConnection()`. Imprime el tiempo total en milisegundos de cada enfoque.
