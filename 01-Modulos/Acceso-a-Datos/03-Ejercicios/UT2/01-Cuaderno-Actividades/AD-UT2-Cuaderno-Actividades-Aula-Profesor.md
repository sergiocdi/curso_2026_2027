## 💻 Actividad 2.2: Operaciones CRUD con PreparedStatement y Claves Autogeneradas
- **Bloque**: Bloque 1 · Conectividad y CRUD | **Alineación**: `RA2 (CE2.c, CE2.d)`
- **Duración**: 35 minutos | **Dificultad**: Intermedia

### 📋 Descripción y Enunciado
Creación de la tabla de productos con columna identity en Oracle, inserción de registros parametrizados recuperando el ID generado con Statement.RETURN_GENERATED_KEYS, actualización de stock y eliminación controlada.

> **Reto de Aula**: Crea la tabla `productos` en tu esquema Oracle con columnas `id_producto NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`, `nombre VARCHAR2(100)`, `precio NUMBER(10,2)`, `stock NUMBER(5)`. Desarrolla una clase `GestionProductosCRUD` que inserte 2 productos recuperando sus IDs generados, actualice el precio del primero y verifique el conteo de filas afectadas.

### 🛠️ Instrucciones y Métodos Clave
| Instrucción / Método | Acción en Disco / Memoria / Servidor |
| :--- | :--- |
| `conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)` | Precompila la sentencia SQL de inserción habilitando el canal de retorno para los identificadores generados automáticamente. |
| `ps.setBigDecimal(index, valor) / ps.setString(index, valor)` | Asigna parámetros fuertemente tipados a las posiciones '?' de la sentencia precompilada sin riesgo de inyección SQL. |
| `ps.executeUpdate()` | Ejecuta la sentencia DML en Oracle y retorna el número de filas afectadas en la base de datos. |
| `ps.getGeneratedKeys()` | Retorna un ResultSet especial que contiene las claves primarias autogeneradas por la base de datos. |

### 🔑 Solución Oficial de Referencia
```java
package es.cifpaviles.dam2.ad.ut2;

import java.math.BigDecimal;
import java.sql.*;

public class GestionProductosCRUD {
    private static final String URL = "jdbc:oracle:thin:@localhost:1521:xe";
    private static final String USER = "c##dam2_user";
    private static final String PASS = "dam2_pass";

    public static void main(String[] args) {
        String sqlInsert = "INSERT INTO productos (nombre, precio, stock) VALUES (?, ?, ?)";
        String sqlUpdate = "UPDATE productos SET precio = ? WHERE id_producto = ?";

        try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {
            // 1. Inserción con recuperación de ID
            long idGenerado = -1;
            try (PreparedStatement ps = conn.prepareStatement(sqlInsert, Statement.RETURN_GENERATED_KEYS)) {
                ps.setString(1, "Monitor Curvo 27 Samsung");
                ps.setBigDecimal(2, new BigDecimal("249.99"));
                ps.setInt(3, 8);
                
                int filas = ps.executeUpdate();
                System.out.println("Filas insertadas: " + filas);

                try (ResultSet rsKeys = ps.getGeneratedKeys()) {
                    if (rsKeys.next()) {
                        idGenerado = rsKeys.getLong(1);
                        System.out.println("ID autogenerado por Oracle: " + idGenerado);
                    }
                }
            }

            // 2. Actualización de precio
            if (idGenerado > 0) {
                try (PreparedStatement psUp = conn.prepareStatement(sqlUpdate)) {
                    psUp.setBigDecimal(1, new BigDecimal("229.50"));
                    psUp.setLong(2, idGenerado);
                    int act = psUp.executeUpdate();
                    System.out.println("Filas actualizadas para ID " + idGenerado + ": " + act);
                }
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

## 💻 Actividad 2.3: Navegación de ResultSet y Tratamiento Estricto de NULLs
- **Bloque**: Bloque 1 · Conectividad y CRUD | **Alineación**: `RA2 (CE2.c, CE2.e)`

### 📋 Descripción y Enunciado
Consulta con filtros dinámicos, navegación mediante ResultSet, obtención tipada de fechas con la API moderna java.time (LocalDate) y resolución segura de columnas numéricas que admiten valores NULL en Oracle.

> **Reto de Aula**: Añade una columna `descuento NUMBER(5,2)` a la tabla `productos` que admita nulos. Inserta un producto sin descuento y otro con 10% de descuento. Desarrolla un programa que consulte todos los productos e imprima en consola si el descuento es NULL o tiene un valor numérico real, utilizando tanto `wasNull()` como `rs.getObject("descuento", Double.class)`.

### 🛠️ Instrucciones y Métodos Clave
| Instrucción / Método | Acción en Disco / Memoria / Servidor |
| :--- | :--- |

| `ResultSet.wasNull()` | Comprueba si la última columna primitiva leída (getInt, getDouble, getLong) contenía un valor NULL en la base de datos. |

### 🔑 Solución Oficial de Referencia
```java
package es.cifpaviles.dam2.ad.ut2;

import java.math.BigDecimal;
import java.sql.*;

public class ConsultaProductosNullSafe {
    private static final String URL = "jdbc:oracle:thin:@localhost:1521:xe";
    private static final String USER = "c##dam2_user";
    private static final String PASS = "dam2_pass";

    public static void main(String[] args) {
        String sql = "SELECT id_producto, nombre, precio, descuento FROM productos ORDER BY id_producto";

        try (Connection conn = DriverManager.getConnection(URL, USER, PASS);
             PreparedStatement ps = conn.prepareStatement(sql);
             ResultSet rs = ps.executeQuery()) {

            System.out.println("ID  | NOMBRE                        | PRECIO   | DESCUENTO");
            System.out.println("----+-------------------------------+----------+----------");
            while (rs.next()) {
                long id = rs.getLong("id_producto");
                String nombre = rs.getString("nombre");
                BigDecimal precio = rs.getBigDecimal("precio");

                // Lectura moderna con getObject (permite null natural)
                Double descuento = rs.getObject("descuento", Double.class);
                String descStr = (descuento != null) ? String.format("%.2f%%", descuento) : "[SIN DESCUENTO]";

                System.out.printf("%-4d| %-30s| %-9.2f| %s\n", id, nombre, precio, descStr);
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

## 💻 Actividad 2.4: Invocación de Procedimientos Almacenados PL/SQL
- **Bloque**: Bloque 1 · Conectividad y CRUD | **Alineación**: `RA2 (CE2.f)`
- **Duración**: 35 minutos | **Dificultad**: Avanzada

### 📋 Descripción y Enunciado
Creación de un procedimiento PL/SQL en Oracle con parámetros IN y OUT, e invocación desde Java mediante CallableStatement, registrando los tipos SQL de salida con java.sql.Types.

> **Reto de Aula**: Crea en Oracle el procedimiento `sp_resumen_producto(p_id IN NUMBER, p_precio OUT NUMBER, p_estado OUT VARCHAR2)`. Si el stock es > 0 el estado es 'DISPONIBLE', si es 0 'AGOTADO'. ### 🛠️ Instrucciones y Métodos Clave
| Instrucción / Método | Acción en Disco / Memoria / Servidor |
| :--- | :--- |
| `conn.prepareCall("{ call sp_nombre(?, ?) }")` | Crea la sentencia invocadora de subprogramas en el servidor de base de datos. |
| `cs.setLong(index, valor)` | Asigna valores a los parámetros formales de entrada (IN). |
| `cs.registerOutParameter(index, Types.TIPO)` | Declara ante el driver JDBC qué tipo de dato SQL se espera recibir de un parámetro de salida (OUT). |
| `cs.execute()` | Ejecuta el bloque PL/SQL en el motor Oracle. |
| `cs.getBigDecimal(index) / cs.getString(index)` | Extrae el valor devuelto por el parámetro de salida tras la ejecución. |

### 🔑 Solución Oficial de Referencia
```java
package es.cifpaviles.dam2.ad.ut2;

import java.math.BigDecimal;
import java.sql.*;

public class InvocacionPLSQLTest {
    private static final String URL = "jdbc:oracle:thin:@localhost:1521:xe";
    private static final String USER = "c##dam2_user";
    private static final String PASS = "dam2_pass";

    public static void main(String[] args) {
        // En Oracle:
        // CREATE OR REPLACE PROCEDURE sp_resumen_producto(
        //   p_id IN NUMBER, p_precio OUT NUMBER, p_estado OUT VARCHAR2
        // ) AS
        //   v_stock NUMBER;
        // BEGIN
        //   SELECT precio, stock INTO p_precio, v_stock FROM productos WHERE id_producto = p_id;
        //   IF v_stock > 0 THEN p_estado := 'DISPONIBLE'; ELSE p_estado := 'AGOTADO'; END IF;
        // END;

        String callSql = "{ call sp_resumen_producto(?, ?, ?) }";
        long idProductoABuscar = 1L;

        try (Connection conn = DriverManager.getConnection(URL, USER, PASS);
             CallableStatement cs = conn.prepareCall(callSql)) {

            cs.setLong(1, idProductoABuscar);                 // IN
            cs.registerOutParameter(2, Types.NUMERIC);       // OUT precio
            cs.registerOutParameter(3, Types.VARCHAR);       // OUT estado

            cs.execute();

            BigDecimal precio = cs.getBigDecimal(2);
            String estado = cs.getString(3);

            System.out.println("Resultado Procedimiento para ID " + idProductoABuscar + ":");
            System.out.println("Precio devuelto: " + precio + " €");
            System.out.println("Estado de stock: " + estado);

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

## 💻 Actividad 2.5: Gestión Transaccional ACID Bancaria y Savepoints
- **Bloque**: Bloque 2 · Transacciones y Pools | **Alineación**: `RA2 (CE2.d, CE2.g)`
- **Duración**: 40 minutos | **Dificultad**: Avanzada

### 📋 Descripción y Enunciado
Control manual de transacciones para garantizar atomicidad absoluta en transferencias de fondos entre cuentas bancarias. Uso de setAutoCommit(false), commit(), rollback() en bloque catch y creación de Savepoints intermedios.

> **Reto de Aula**: Crea una tabla `cuentas_bancarias (id NUMBER PRIMARY KEY, titular VARCHAR2(50), saldo NUMBER(10,2))`. Inserta dos cuentas con 1.000€ cada una. Realiza una transferencia transaccional de 300€ de la cuenta 1 a la cuenta 2. Simula un fallo de negocio (saldo insuficiente o excepción) y comprueba que ningún saldo queda modificado gracias al rollback.

### 🛠️ Instrucciones y Métodos Clave
| Instrucción / Método | Acción en Disco / Memoria / Servidor |
| :--- | :--- |
| `conn.setAutoCommit(false)` | Desactiva la confirmación inmediata automática. Comienza un bloque transaccional atómico. |
| `conn.setSavepoint("nombre")` | Establece un punto de restauración intermedio dentro de la transacción activa. |
| `conn.rollback(savepoint)` | Deshace exclusivamente las operaciones realizadas con posterioridad al savepoint indicado. |
| `conn.commit()` | Confirma de manera permanente y atómica todas las operaciones de la transacción en el almacenamiento de Oracle. |
| `conn.setAutoCommit(true)` | Restaura el estado original de la conexión en el bloque finally. |

### 🔑 Solución Oficial de Referencia
```java
package es.cifpaviles.dam2.ad.ut2;

import java.math.BigDecimal;
import java.sql.*;

public class TransferenciaBancariaTransaccional {
    private static final String URL = "jdbc:oracle:thin:@localhost:1521:xe";
    private static final String USER = "c##dam2_user";
    private static final String PASS = "dam2_pass";

    public static void main(String[] args) {
        realizarTransferencia(1L, 2L, new BigDecimal("300.00"), false);
        // Descomentar para simular fallo y verificar rollback:
        // realizarTransferencia(1L, 2L, new BigDecimal("2000.00"), true);
    }

    public static void realizarTransferencia(long origen, long destino, BigDecimal importe, boolean simularFallo) {
        String sqlDebitar = "UPDATE cuentas_bancarias SET saldo = saldo - ? WHERE id = ? AND saldo >= ?";
        String sqlAcreditar = "UPDATE cuentas_bancarias SET saldo = saldo + ? WHERE id = ?";

        try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {
            conn.setAutoCommit(false); // 1. Iniciar transacción manual
            try {
                // Paso A: Retirar fondos de cuenta origen
                try (PreparedStatement psDeb = conn.prepareStatement(sqlDebitar)) {
                    psDeb.setBigDecimal(1, importe);
                    psDeb.setLong(2, origen);
                    psDeb.setBigDecimal(3, importe); // Restricción saldo suficiente
                    int filas = psDeb.executeUpdate();
                    if (filas == 0) {
                        throw new IllegalStateException("Saldo insuficiente o cuenta origen inexistente.");
                    }
                }

                if (simularFallo) {
                    throw new RuntimeException("¡Fallo catastrófico simulado antes de acreditar!");
                }

                // Paso B: Ingresar fondos en cuenta destino
                try (PreparedStatement psAcr = conn.prepareStatement(sqlAcreditar)) {
                    psAcr.setBigDecimal(1, importe);
                    psAcr.setLong(2, destino);
                    int filas = psAcr.executeUpdate();
                    if (filas == 0) {
                        throw new IllegalStateException("Cuenta destino no encontrada.");
                    }
                }

                conn.commit(); // 2. Confirmación atómica
                System.out.println("[OK] Transferencia de " + importe + " € completada exitosamente.");
            } catch (Exception e) {
                System.err.println("[ROLLBACK] Error en la transferencia: " + e.getMessage());
                conn.rollback(); // 3. Deshacer cualquier cambio intermedio
            } finally {
                conn.setAutoCommit(true); // 4. Restaurar estado
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

## 💻 Actividad 2.7: Configuración de Pool HikariCP y Benchmark Concurrente
- **Bloque**: Bloque 2 · Transacciones y Pools | **Alineación**: `RA2 (CE2.h)`
- **Duración**: 35 minutos | **Dificultad**: Avanzada

### 📋 Descripción y Enunciado
Configuración de un pool HikariDataSource de alto rendimiento en Java 21 y comparativa de tiempos de respuesta frente al DriverManager clásico ejecutando 100 consultas consecutivas.

> **Reto de Aula**: Añade `com.zaxxer:HikariCP:5.1.0` a tu `pom.xml`. Implementa una clase `BenchmarkPoolHikari` que ejecute 100 consultas `SELECT 1 FROM DUAL`. Primero usando `DriverManager.getConnection()` en cada iteración y luego usando `HikariDataSource.getConnection()`. Imprime el tiempo total en milisegundos de cada enfoque.

### 🛠️ Instrucciones y Métodos Clave
| Instrucción / Método | Acción en Disco / Memoria / Servidor |
| :--- | :--- |
| `new HikariConfig()` | Objeto de configuración de parámetros del pool: URL, credenciales, tamaños de piscina y timeouts. |
| `config.setMaximumPoolSize(10)` | Fija el número máximo de conexiones físicas simultáneas mantenidas contra Oracle. |
| `new HikariDataSource(config)` | Inicializa el pool y pre-calienta las conexiones mínimas en segundo plano. |
| `dataSource.getConnection()` | Toma una conexión pre-calentada del pool en microsegundos. |
| `conn.close() (con HikariCP)` | Interceptado por el proxy del pool: la conexión física no se destruye, sino que se devuelve a la piscina. |

### 🔑 Solución Oficial de Referencia
```java
package es.cifpaviles.dam2.ad.ut2;

import com.zaxxer.hikari.HikariConfig;
import com.zaxxer.hikari.HikariDataSource;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;

public class BenchmarkPoolHikari {
    private static final String URL = "jdbc:oracle:thin:@localhost:1521:xe";
    private static final String USER = "c##dam2_user";
    private static final String PASS = "dam2_pass";
    private static final int ITERACIONES = 50;

    public static void main(String[] args) throws Exception {
        System.out.println("=== BENCHMARK: DRIVERMANAGER vs HIKARICP (" + ITERACIONES + " consultas) ===");

        // 1. Prueba con DriverManager
        long t1 = System.currentTimeMillis();
        for (int i = 0; i < ITERACIONES; i++) {
            try (Connection conn = DriverManager.getConnection(URL, USER, PASS);
                 PreparedStatement ps = conn.prepareStatement("SELECT 1 FROM DUAL");
                 ResultSet rs = ps.executeQuery()) {
                if (rs.next()) rs.getInt(1);
            }
        }
        long duracionDriver = System.currentTimeMillis() - t1;
        System.out.println("Tiempo con DriverManager: " + duracionDriver + " ms");

        // 2. Prueba con HikariCP
        HikariConfig config = new HikariConfig();
        config.setJdbcUrl(URL);
        config.setUsername(USER);
        config.setPassword(PASS);
        config.setMaximumPoolSize(10);
        config.setMinimumIdle(2);

        try (HikariDataSource ds = new HikariDataSource(config)) {
            long t2 = System.currentTimeMillis();
            for (int i = 0; i < ITERACIONES; i++) {
                try (Connection conn = ds.getConnection();
                     PreparedStatement ps = conn.prepareStatement("SELECT 1 FROM DUAL");
                     ResultSet rs = ps.executeQuery()) {
                    if (rs.next()) rs.getInt(1);
                }
            }
            long duracionHikari = System.currentTimeMillis() - t2;
            System.out.println("Tiempo con HikariCP:     " + duracionHikari + " ms");
            System.out.printf("Aceleración conseguida: %.1fx más rápido\n", (double) duracionDriver / duracionHikari);
        }
    }
}
```

Diseño e implementación de un Data Access Object desacoplado: definición de ProductoDTO como Java Record, interfaz ProductoDAO, e implementación ProductoDAOJdbc inyectando javax.sql.DataSource.

> **Reto de Aula**: Implementa el patrón DAO completo para la entidad `Producto` con su correspondiente Record `ProductoDTO`, interfaz `ProductoDAO` y clase `ProductoDAOJdbc`. Prueba en una clase `AppTestDAO` la inserción, búsqueda por ID con `Optional` y listado completo.

### 🛠️ Instrucciones y Métodos Clave
| Instrucción / Método | Acción en Disco / Memoria / Servidor |
| :--- | :--- |
| `public record ProductoDTO(...)` | Definición inmutable del modelo de transferencia en Java 21. |
| `public interface ProductoDAO` | Contrato de persistencia con métodos CRUD estándar (create, findById, findAll, update, delete). |
| `Inyección de DataSource` | El DAO recibe javax.sql.DataSource por constructor, desacoplándose de cómo se obtienen las conexiones. |
| `Optional<ProductoDTO>` | Retorno expresivo que evita NullPointerException cuando no existe el registro buscado. |

### 🔑 Solución Oficial de Referencia
```java
package es.cifpaviles.dam2.ad.ut2.dao;

import java.math.BigDecimal;
import java.util.List;
import java.util.Optional;

// 1. DTO (Java Record)
public record ProductoDTO(Long id, String nombre, BigDecimal precio, Integer stock) {}

// 2. Interfaz DAO
interface ProductoDAO {
    void create(ProductoDTO prod);
    Optional<ProductoDTO> findById(Long id);
    List<ProductoDTO> findAll();
    void update(ProductoDTO prod);
    void delete(Long id);
}

// 3. Implementación JDBC
import javax.sql.DataSource;
import java.sql.*;
import java.util.ArrayList;

public class ProductoDAOJdbc implements ProductoDAO {
    private final DataSource dataSource;

    public ProductoDAOJdbc(DataSource dataSource) {
        this.dataSource = dataSource;
    }

    @Override
    public void create(ProductoDTO prod) {
        String sql = "INSERT INTO productos (nombre, precio, stock) VALUES (?, ?, ?)";
        try (Connection conn = dataSource.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, prod.nombre());
            ps.setBigDecimal(2, prod.precio());
            ps.setInt(3, prod.stock());
            ps.executeUpdate();
        } catch (SQLException e) {
            throw new RuntimeException("Error al crear producto: " + prod.nombre(), e);
        }
    }

    @Override
    public Optional<ProductoDTO> findById(Long id) {
        String sql = "SELECT id_producto, nombre, precio, stock FROM productos WHERE id_producto = ?";
        try (Connection conn = dataSource.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setLong(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return Optional.of(new ProductoDTO(
                        rs.getLong("id_producto"),
                        rs.getString("nombre"),
                        rs.getBigDecimal("precio"),
                        rs.getInt("stock")
                    ));
                }
                return Optional.empty();
            }
        } catch (SQLException e) {
            throw new RuntimeException("Error al buscar producto ID " + id, e);
        }
    }

    @Override
    public List<ProductoDTO> findAll() {
        String sql = "SELECT id_producto, nombre, precio, stock FROM productos ORDER BY id_producto";
        List<ProductoDTO> lista = new ArrayList<>();
        try (Connection conn = dataSource.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql);
             ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                lista.add(new ProductoDTO(
                    rs.getLong("id_producto"),
                    rs.getString("nombre"),
                    rs.getBigDecimal("precio"),
                    rs.getInt("stock")
                ));
            }
            return lista;
        } catch (SQLException e) {
            throw new RuntimeException("Error al listar productos", e);
        }
    }

    @Override public void update(ProductoDTO prod) { /* DML UPDATE */ }
    @Override public void delete(Long id) { /* DML DELETE */ }
}
```
