# 💻 Ejercicio Guiado: Capa DAO y CRUD Transaccional de Clientes con JDBC en Oracle

> **Módulo**: [[MOC-Acceso-a-Datos|Acceso a Datos]] | **UD**: [[UD02-Conectores-BBDD-Relacionales|UD02 / UT2]] | **RAs**: `RA2 (CE2.a, CE2.b, CE2.c)` | **Tiempo**: `120 min`

---

## 📋 Enunciado

Implementar una capa de persistencia completa utilizando el conector oficial JDBC para **Oracle Database** y aplicando el patrón de diseño `Data Access Object (DAO)` sobre la tabla `CLIENTES`:

1. **Estructura de la tabla en Oracle**:
   ```sql
   CREATE TABLE CLIENTES (
       ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       DNI VARCHAR2(10) UNIQUE NOT NULL,
       NOMBRE VARCHAR2(100) NOT NULL,
       EMAIL VARCHAR2(100) NOT NULL,
       SALDO NUMBER(10,2) DEFAULT 0.00
   );
   ```

2. **Diseño de la Capa DAO**:
   - Crear el modelo DTO `Cliente` (con `id`, `dni`, `nombre`, `email`, `saldo`).
   - Crear la interfaz `ClienteDAO`:
     - `Optional<Cliente> findById(int id)`
     - `List<Cliente> findAll()`
     - `boolean insert(Cliente cliente)`
     - `boolean update(Cliente cliente)`
     - `boolean delete(int id)`
   - Implementar `ClienteDAOOracleImpl` utilizando siempre `PreparedStatement` para prevenir la inyección SQL.

3. **Control Transaccional**:
   - Implementar una operación de negocio `transferirSaldo(int idOrigen, int idDestino, double importe)`:
     - Debe ejecutarse dentro de una transacción manual con `con.setAutoCommit(false)`.
     - Si alguna actualización falla o no hay saldo suficiente, realizar `con.rollback()`.
     - Si ambas tienen éxito, ejecutar `con.commit()`.

---

## 🛠️ Requisitos Técnicos
- Conexión vía JDBC Thin Driver (`jdbc:oracle:thin:@localhost:1521:xe` o SID configurado).
- Gestión de conexiones y sentencias con `try-with-resources`.
- Tratamiento de excepciones `SQLException` inspeccionando códigos de error específicos de Oracle.
