# RA4: Bases de Datos Objeto-Relacionales y Nativas XML

> **Enunciado Oficial**: Desarrolla aplicaciones que gestionan la información almacenada en bases de datos objeto-relacionales y nativas XML analizando sus características y utilizando los motores y lenguajes de consulta específicos.  
> **Ponderación**: **10%**

---

## 🎯 Criterios de Evaluación Oficiales
| Código | Criterio de Evaluación | Ponderación |
| :---: | :--- | :---: |
| **CE4.a** | Se han identificado las características de las bases de datos objeto-relacionales. | 25% |
| **CE4.b** | Se han utilizado tipos estructurados y colecciones en motores de bases de datos. | 25% |
| **CE4.c** | Se han realizado consultas sobre bases de datos nativas XML (XPath / XQuery). | 30% |
| **CE4.d** | Se han integrado sentencias XML en aplicaciones mediante APIs específicas (eXist-db). | 20% |
