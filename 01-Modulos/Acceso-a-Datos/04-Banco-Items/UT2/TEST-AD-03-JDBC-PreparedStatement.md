# ❓ Test: Ventajas de PreparedStatement frente a Statement

> **Módulo**: Acceso a Datos | **UD**: UD02 | **RA**: RA2 | **CE**: CE2.b | **Dificultad**: Media

### Enunciado:
¿Cuáles son las dos ventajas principales de utilizar `PreparedStatement` en lugar de `Statement` en JDBC?

### Opciones:
- [x] A) Previene ataques de inyección SQL mediante el escape automático de parámetros y mejora el rendimiento al precompilar la consulta en el motor de base de datos. *(Correcta)*
- [ ] B) Permite ejecutar consultas sin necesidad de autenticarse con usuario ni contraseña en el motor.
- [ ] C) Transforma de forma automática consultas SQL en bases de datos NoSQL tipo MongoDB.
- [ ] D) Duplica automáticamente las tablas en memoria secundaria para evitar pérdidas de datos.
