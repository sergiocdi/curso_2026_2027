## 🎯 Descripción y Alcance
Plataforma multiplataforma de seguimiento y control de rutas logísticas en tiempo real. Incluye aplicación móvil en Flutter para conductores y backend REST en Java Spring Boot con persistencia relacional en PostgreSQL y caché en Redis.
